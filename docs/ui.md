# Guía de la Interfaz de Usuario (UI)

## Paleta de Colores y Estilo
El diseño de NexuChat prioriza la visibilidad en entornos de baja luz y la legibilidad rápida, utilizando una estética "Dark Mode".
* *Fondo:* Negro carbón profundo.
* *Acentos principales:* Tonos neón (Violeta, Cian) para resaltar llamadas a la acción y botones principales.
* *Tipografía:* Sans-serif moderna, limpia y minimalista.

## Flujo de Navegación
La aplicación se divide en 3 vistas principales accesibles mediante una Barra de Navegación Inferior global:

1. *Radar (Pantalla Principal):* Actúa como el centro de conectividad. Muestra un nodo central emitiendo ondas expansivas concéntricas, el interruptor superior para el "Modo Nexo / Aislado", y los nodos detectados en el perímetro.
2. *Chats:* Bandeja de entrada que lista las conversaciones recientes con indicadores visuales de tiempo y estado de conexión (online/offline). Incluye un botón flotante (FAB) para iniciar nuevas conexiones.
3. *Perfil:* Panel de control de identidad donde se gestiona el Nickname, el "Aura" del nodo, y se visualizan estadísticas de uso (nodos contactados, tiempo en colmena, almacenamiento local usado).
